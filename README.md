# Kriti Priya | Portfolio

Personal portfolio for Associate Product Manager roles. A single static page (`index.html`) with images in `img/`. No build step.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Host on GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
